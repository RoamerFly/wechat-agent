# 迁移

从 0.1.5 升级到 0.1.6 时，已有 Word 与 PDF 原件无需迁移。新建无边框表格或从这类 Word 导出无边框 PDF 需要 0.1.6。

首版没有旧的文档工具状态可迁移。旧附件仍由主体的素材库保存；安装后仅在新的、已授权任务中通过素材引用读取。从 0.1.2 升级到 0.1.3 无需改写已有 DOCX 和 PDF；旧版已安装包仍可使用原有功能。使用标题修订需升级到 0.1.3；图片复刻保留插图需 0.1.4。有边框合并表格的复刻和 PDF 导出需 0.1.5。已保存的文档及修订记录无需迁移。卸载默认保留已经登记的 DOCX/PDF 成品和其来源关系，删除数据需由宿主另外确认。
