# OBS 节目预览

这是一个可选的 Windows 本机工具。主人先在 OBS Studio 中自行启用 WebSocket v5，并配置端口和密码；启用本工具后，**主人可在管理页**读取当前节目场景的 JPEG 预览。本阶段不向大肥鱼 Agent 或模型开放画面。

默认端口是 `4455`。宿主固定连接 `127.0.0.1`，不提供远程主机、局域网地址或 URL 配置。密码由宿主私有保存，不显示给 Agent，也不会随工具包发布。

“开始预览”读取第一帧；“刷新预览”读取下一帧；“停止预览”只关闭本地预览会话。空闲 60 秒也会自动关闭。它不会启动或关闭 OBS，不会切换场景、修改设置、开始或结束推流，也不会携带 OBS 二进制文件。

配置只能在工具停用时修改。未配置密码、OBS 未启动、WebSocket 未启用或密码不匹配时，工具保持不可用并返回具体本机连接原因。
