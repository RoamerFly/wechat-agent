# Windows 专用 OBS 安装

此入口使用独立的 OBS Studio 33.0.1 x64 便携副本。专用输出可使用已登记的 MP4 成品；没有选择节目时仍显示测试色板。安装成功只表示本机具备输出条件。开始直播还需要平台适配器和本次开播授权。

1. 从本文末尾的官方发布页取得 **33.0.1 Windows x64 ZIP**，保存在本机。
2. 在「项目工具」打开「OBS 节目预览」详情，找到「专用节目输出」。它与下方的外部 OBS 只读预览分别配置。
3. 填入本机 ZIP 的完整路径，确认安装范围后，点击弹窗右上角的「安装专用输出」。宿主核对固定 SHA-256，再解压和生成运行文件清单；不执行脚本、不下载其他内容。
4. 显示安装完成后正常退出并重新打开成长站。登录后的直播状态接口 `/api/local/live` 会显示 `encoder: ready`。直播目标列表仍取决于应用授权。

安装目录固定在站点私有数据目录的 `managed-obs\studio`，位于大肥鱼工作空间之外。安装失败或取消只清理本次暂存文件，不覆盖已有副本；已有或损坏的安装均显示只读状态。需要移走旧副本时，先完全停止成长站，再将整个 `managed-obs` 移到别处。重新安装和启动后会校验新副本。旧 PowerShell 安装入口已由宿主安装器替代，发行包不再提供该脚本。

私有编码器使用自己的 Windows 桌面和节目配置。只读节目预览继续连接由你独立启动的 OBS。本机校验失败时，优先检查 ZIP 版本、目录位置和是否修改了已安装的模块。平台未登记或授权不可用时，目标列表为空。

在本机聊天里让大肥鱼使用已有作品时，她可先调用 `artifact_publish` 取得成品编号及 SHA-256，再按需发现 `app_live`。开始会话同时提供 `program_artifact_id` 与 `program_sha256`，`program_loop` 指定是否循环；原会话查询和停止只提供原编号。节目引用跟随原任务保存，不能在查询或重试中悄悄换片。播放完一遍不等于结束直播：未开启循环时媒体源按其结束行为停止呈现，直播会话仍按授权时长或明确停止收口。

宿主先验证原件、身份及来源，读取视频元数据并解码一帧。编码器使用另行核验过的私有文件，按视频比例居中显示并保留音频；家目录原文件后来被编辑不改变已选版本。来源被遗忘或家目录授权撤销后，输出检查会停止原会话。首版节目输入明确限于 MP4，不接受网络播放列表、任意 OBS 配置或媒体 URL；其他容器可先用媒体工具转码。该本地媒体源使用 [OBS 33.0.1 的官方媒体源设置](https://github.com/obsproject/obs-studio/blob/33.0.1/plugins/obs-ffmpeg/obs-ffmpeg-source.c)。生成配置、实际编码画面及平台开播是三个不同的验证阶段，部署记录分别说明。

[OBS 官方下载](https://obsproject.com/download?os=windows_x86) · [OBS 33.0.1 发布记录](https://github.com/obsproject/obs-studio/releases/tag/33.0.1)

接入桌面直播客户端时，受管输出可以先准备 OBS 虚拟摄像头画面，再由已授权的应用适配器提交平台开播。摄像头使用已登记的 MP4 节目及固定版本，宿主会核对本次启动日志与持续更新的帧队列。出现占用错误时，应先结束其他正在使用 OBS 虚拟摄像头的任务。该模式只传出画面，客户端的音频输入需要单独核对。

抖音官方提供在直播伴侣中添加 OBS 摄像头的操作说明。当前接入代码已具备本机来源生命周期，真实专用 OBS、摄像头驱动、伴侣接收、账号资格与观众端效果仍待后续安装环境验收。主人当前选择暂缓下载安装，软件保持现有部署状态。[官方摄像头接入指南](https://streamingtool.douyin.com/docs/guide_yr6qkl09)

在「应用 → 抖音 → 账号与使用」中有「直播伴侣」检查区。安装后可填写实际主程序的 EXE 完整路径，点击「检查程序」读取版本。请选择安装目录中的主程序，不是下载的安装包或快捷方式。检查不打开程序、不保存登录、不授予开播权限；显示版本后仍需核对发布者、客户端登录、音画输入及直播控制。当前没有安装时可以留空，不影响抖音原有网页登录与作品功能。

主人可将官方直播伴侣安装到发行目录的 `connected-apps/douyin/runtime/live-companion`，使客户端运行文件跟随抖音应用区域整理。Windows 安装器可能要求系统管理员授权；只有安装结束并检查到实际主程序，才能算安装完成。安装包的版本和客户端版本分别核对，不以安装包文件名代替主程序身份。客户端保存登录的位置仍由官方软件决定，不将这些资料复制到可编辑的应用接入版本中。
