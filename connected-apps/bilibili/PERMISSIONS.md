# 读取授权

首次启动读取关闭。主人启用并保存 BV 列表后，宿主只向固定 B 站 HTTPS 接口发送获准的 BV 号，使用匿名连接。设置和授权版本存放在宿主私有目录。家目录中的应用源码及配置示例无法修改授权。

关闭读取或移除一个 BV 号后，宿主拒绝后续读取和该授权下的缓存复用。已经保存的本地聊天由原会话历史管理。

独立浏览器授权默认关闭。开启后，宿主为该匿名连接使用专属 Edge 数据目录和私有调试管道，按次读取获准 BV 页。关闭浏览器开关会取消在途页面读取并使相关缓存失效。

播放授权也默认关闭，需在独立浏览器已获权的前提下另行开启。宿主只解析清单内的公开 BV，短时在内存中向专属 Edge 提供获准媒体。撤销任一级授权会取消正在进行的采样。

评论授权默认关闭，使用获准 BV 对应的稿件编号分页读取公开一级评论。只将评论文字、评论编号和时间交给观察结果。撤权会取消在途读取，旧授权下的分页和缓存不能继续使用。

音轨授权只覆盖同一 BV 清单内的匿名公开单段 MP4。宿主本地解码，向已启用的本机语音识别工具只传递当前窗口的 PCM；不授予微信账号、文件系统通用读取或远程模型调用权限。应用和工具任一授权版本变化后，旧音轨证据不能继续使用。

## 发布授权

主人在站点私有数据目录的 `apps/bilibili/publication-settings.json` 独立登记已获准投稿的应用和账号 OAuth。公开读取权限不能用于投稿。宿主只让发布适配器读取该任务选定的成品，并在每次平台写入前重新检查账号、发布授权、原请求和成品来源。

签名请求只发往固定会员接口。分片主机只接收上传令牌和该分片的字节。凭据、上传令牌及指纹留在宿主。停用发布后，同一套未过期的凭据可查询已提交的原稿件。凭据更换或过期后的旧稿件对账需要另行核实。取消不会撤回已提交作品。

主人登记凭据时，宿主只向固定的开放平台账号信息接口发起签名查询。成功返回的应用范围账号标识只用于核验和绑定，不发送给模型。已核验的同一应用和账号可轮换有效令牌来只读对账。首次升级旧授权时须验证原令牌。

网页授权由主人打开官方授权页，并将回跳地址交回本机鉴权界面。宿主按原本机主人、管理会话、回调地址和一次性状态匹配回跳。兑换和续期使用固定官方端点。刷新令牌留在宿主私有配置，发送续期请求前持久记录领取并移除旧刷新令牌。结果不确定时暂停新投稿，等待主人重新网页授权。

原任务已开始投稿且缺少回执时，主人可查询同一已核验且仍启用的发布账号。适配器在查询前后核对原任务账号和授权版本。返回指定 BV 的公开状态可以保留为主人观察。标题候选只用于当前核对，模型工具无法读取候选或保存的观察。
