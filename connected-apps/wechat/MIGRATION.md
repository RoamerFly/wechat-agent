# 迁移

此版本迁移应用身份、工具声明、消息/成员目录协议、来源元数据投影，以及文字发送、账号动作、撤回、原附件取得、文件转发、媒体发送、回执查询和微信分享读取编排。视频号仍复用已安装的分享读取工具以及宿主的账号授权、配置和媒体能力；无需复制既有私密配置或素材。原幂等键与操作编号保持不变，未知结果继续查询原任务；提交前核对授权及来源，实际回执由宿主入账。存储读取、更正/遗忘屏障和账号授权由宿主提供窄接口；应用不取得聊天数据库、账号凭据或其他账号句柄。原账号、来源编号、群偏好、素材、记忆、任务和回执继续由现有宿主存储管理。

首次安装将经摘要核验的文件原子发布到 Connected Apps/wechat。相同描述符重试保留现有编辑。不同版本或已存在的无关目录返回冲突，保留原内容。安装中断后重试创建完整目录，临时目录不代表应用已启用。

0.1.12 在独立工作器策略中增加 `history_grants`，旧策略读取为关闭，不自动授予历史访问。管理接口的 `history_threads` 限于回复范围；旧客户端省略该字段时保留有效授权，撤销父级会话同时撤销读取。首次启用后暂停旧工作器，主人重新启动才接收新授权下的消息。此项不复制原聊天数据库，也不修改既有长期记忆。

卸下此发行源不会清除宿主资料。Windows 独立预览可选启动随包原生组件，并可由主人登记新账号及发起扫码。首次启动使用独立空目录，正式账号资料与旧服务在此步不迁移。独立预览可为各账号启用文字回复工作器。授权、记忆及发送账本保存在宿主私有目录，使用同一份宿主模型配置。已有账号可通过 Windows 原生离线导出及导入保留账号编号。独立宿主再从隔离旧快照预演并导入只读发送记录，保留可重新授权的回复范围建议。导入先保持暂停，授权由主人重新选择。原始资料及待处理任务继续保留在旧快照，详情见宿主《Windows 预览操作说明》。

0.1.23 支持为单个已授权会话预演并接续旧记忆。主人需确认实际账号相同。接续保存到宿主的私有会话记录，运行中的 Agent 可按需读取，实时记忆库及队列保持独立。撤销历史授权后，旧授权下的接续记录失去可读性。
