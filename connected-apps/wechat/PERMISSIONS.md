# 权限

目录写入由本机主人授权和稳定鱼身份决定。安装发行源不授予微信账号权限。

微信连接、登录、会话范围、动作授权和原投递回执由宿主核对。应用目录中不保存口令、API Key、Cookie 或登录材料。家目录中的代码只使用宿主授予的工作区和执行能力。

暂停微信连接会阻止宿主下一次提交，原生后台已接手的任务继续按原回执核对。

原附件读取默认关闭，由主人在回复范围内逐会话开启。Agent 只可选择本轮消息或已核验的引用；原件保存在当前连接的宿主私有目录，工具返回素材编号和校验信息。撤销后旧素材编号立即失效，重新授权会建立新授权版本。Agent 暂停时，仅已登录主人的管理接口可在现有范围内取得原件。

附件回复默认关闭，范围须包含在原附件读取授权内。准备工具仅允许明确面向大肥鱼的请求使用本轮或核验引用中的附件，交付目标由当前会话决定。撤销后旧请求不能提交或续发，已提交的原任务仍可核对回执。

家目录作品另外保存主人确认的交付授权，绑定一件成品快照、当前连接、会话和请求者。群成员只能发现授予自己的作品；修改应用声明不会增加可见范围。撤销作品授权会暂停本连接，重新启用须使用新的授权请求编号。家目录暂停也阻止作品交付，恢复后需重新授权交付。

历史消息和群成员的读取须在已批准的回复会话范围内单独开启。工具不接受其他会话或账号参数，不向模型暴露原生游标、数据库路径或账号凭据。消息原文读取会核对已知来源身份、更正、遗忘和冲突；读取本身不会将历史重新提取为长期记忆，也不发送已读回执。

通讯录由本机主人在应用页按连接查看。大肥鱼只有在主人对该连接单独授权后，才能在本地聊天使用通讯录查询。这个授权不开放给微信私聊或群聊。结果仅包含联系人 ID、显示名和本机快照覆盖状态；旧授权下的模型续读位置在撤权后失效。

本机群目录由主人按登录连接查看。主人可在应用页明确选择群和目标免打扰状态并确认，也可按连接和群 ID 授权本地聊天中的 Agent 设置免打扰。群改名与设置本人群昵称由主人在应用页确认，各自检查原生能力。昵称目标由登录账号及精确群 ID 确定。免打扰授权只覆盖免打扰。Agent 权限默认关闭，微信入站私聊与群聊不可使用。宿主校验账号、精确群、暂停状态、本地消息来源及授权版本，再持久登记请求后提交。取消授权会阻止尚未提交的操作，已交给原生服务的操作可在应用页查原回执。待核对或结果未知的操作仍占用该群对应动作的提交位置。群操作丢失原生响应时，宿主按原请求键只读查询。

撤回入口要求本地主人确认。宿主从同一连接的投递回执和原生消息同时核对会话、发出方向、消息编号与微信服务端编号。每次只撤回选中的消息。没有原生操作编号时保留结果未知。

视频原件工具使用当前连接的附件读取授权。超出本轮和已核验引用的原件还需要同会话的历史授权。视频号直链、解密参数及下载位置由宿主持有，缓存与原卡片和授权版本绑定。此工具只提供原件与探测数据，分享原件未获附件回复授权。

分享解析回退默认关闭。主人对每个连接单独安装并授予受控网络权限，配置凭据后启用。应用代码只使用宿主批准的卡片和网络回调。解析凭据仅出现在宿主向配置声明所指平台发出的请求中。解析工具的启用权限与会话读取权限分别核验。
