# 微信应用

微信接入包含登录、收发消息、通讯录、引用、撤回和微信分享读取。此目录是应用发行源，桌面可将它安装到大肥鱼家目录的 Connected Apps/wechat。

当前版本迁出了应用及连接身份、11 个工具声明、消息与成员读取协议、来源元数据投影及语音分段参数声明。运行中的兼容接入仍由宿主装配，文字发送、账号动作、撤回、原附件取得、文件转发、媒体投递与回执查询编排已迁入应用适配器。授权、原素材、分段队列、取消和回执继续由宿主通过绑定原请求的接口管理。读取前后由宿主核对当前授权；只有成功返回的消息页才可登记为任务来源，成员列表不能当作聊天原文。微信卡片、视频号来源、读取回退及解析校验也由适配器处理。实际读取调用宿主的网络、分享读取和媒体理解能力。独立桌面可以单独选择运行包，在宿主核验原生进程归属后登记账号、发起扫码并查看登录状态。安装此发行源仍只准备可编辑源码。

宿主在安装时校验 app.json 及文件摘要。大肥鱼可以编辑安装目录内的代码、说明和任务文件。修改声明不改变账号授权。工作文件保存在 workspace，非密钥设置保存在 config。再次安装相同发行源会保留已有编辑。升级到不同发行源需先处理旧版本及在途任务。

## 安装

在桌面发行包选择包含微信应用目录。使用管理接口 GET /api/local/apps/catalog 核对摘要，再以 POST /api/local/apps/wechat/install 提交 digest 与当前家目录 revision。家目录必须已经准备且授权。

## 运行组件

adapter/entry.json 标识宿主兼容入口和独立主体的原生账号接入入口。Windows 独立桌面从经摘要校验的随包组件启动 wx，原生私有目录固定在宿主 data_root/apps/wechat/native。独立预览支持各连接独立配置文字回复范围、启动和暂停工作器。旧版账号可通过原生离线档案导入和宿主预演保留账号编号及只读发送记录，核对后再启用。登录材料、聊天数据库及回执存放在宿主私有目录。

主人可在连接的回复范围内单独开启附件读取。`wechat_file_read` 用于取得本轮或已核验引用的文件、图片、语音和视频原件，返回素材编号、类型、大小和 SHA-256。具体授权和管理下载路径见[本地预览指南](../../docs/guide/local-home-preview.md)。

独立 Windows 桌面的 `wechat_attachment_reply_prepare` 可准备把这类附件发回原会话。读取、准备、上传、微信提交和回执是不同状态。宿主保存原提交编号，微信结果未知时按原任务查询。

`wechat_work_reply` 用于发现和准备主人授予当前请求者的家目录作品。成品通过主体的 `artifact_publish` 或管理页面登记，生成工具沿用同一成品契约。作品按文件交付，读取目录和准备均需现有附件回复授权。

历史读取另行授权，默认关闭。`wechat_read` 在当前会话内查询消息或群成员，按实际返回的游标续读；`wechat_message_read` 按真实消息编号读取正文，续页携带内容摘要以核对版本。消息页保留原发送者和时间，单页按时间正序排列，跨页汇总需按原时间再次排序。`wechat_message_read` 中的分享卡片范围限于发布者资料。

`wechat_video_read` 读取本轮、引用或已获准历史中的普通视频和视频号原件。宿主核对原卡片和实际字节，使用 Windows 运行环境可找到的 FFprobe 检测时长、帧数和尺寸。直链缺失或失效时，可调用主人为当前连接安装并启用的官方分享解析工具。解析工具通过隔离进程和宿主网络代理运行。

`wechat_video_observe` 使用原件的素材和消息编号读取实际帧或音轨，并分别返回已读覆盖和续读位置。需在当前连接授权并配置媒体理解工具。视觉使用远程视觉接口，音轨可选本机识别或已配置的远程 ASR。画面采样、模型截断、无音轨、未识别到词和工具失败各有实际含义。

主人可在回复范围单独开启普通视频的自动读取。只读授权后进入有效回合的视频，先尝试最多 45 秒音轨，无可用转写时才用已配置的视觉服务观察至多 6 帧。按需视频工具可继续读取。群的视频号总结选择继续单独管理。

微信语音消息在会话获准读取附件、连接选择本机识别且已启用媒体理解时进入聊天回合的前置转写。`wechat_voice_transcribe` 可显式读取当前或核验后的引用语音，按 `next_start_seconds` 续读。宿主从原生服务单独获取并校验可播放 WAV，原始 SILK 可继续作为附件读取。本机转写失败时不会改用远程接口。

`wechat_image_observe` 可读取当前或核验后的引用图片。通过已配置的视觉服务观察原图或完整的标准清晰度版本，返回实际版本、来源和观察文字。主人可在连接的回复范围开启「自动读图」，让获准会话的新图片进入符合回复条件的回合。未开启时仍可按需使用图片工具。视觉服务会收到获准的图片字节。

应用页的「通讯录」读取当前连接已经同步到本机的联系人。主人可另外授权 `wechat_contacts`，让大肥鱼在本地聊天中按连接搜索及分页读取。

启用本机文档工坊后，获准会话可用 `wechat_document_inspect` 读取本回合或核验后的引用附件正文。另有历史读取权限时，可以先用 `wechat_read` 查找请求者此前发在本会话的文件，再按原消息编号读取。支持 DOCX 和 PDF。PDF 需要随包提供的文档运行时；带本机扫描组件时，没有文字层的页会按需识别。续读可用 `expected_sha256` 核对同一原件。

在具备附件读取和媒体回复权限的定向请求中，`wechat_document_export_pdf` 可把 DOCX 导出为 PDF。成品与当前请求、原件和会话绑定。工具生成成品后返回待选文件，最终回复选中才进入既有微信队列。原件授权变化时停止尚未提交的发送。

带本机中文 OCR 的文档工坊可通过 `wechat_document_reconstruct_image` 从 PNG 或 JPEG 原件重建可编辑标题、段落和单个表格。0.1.5 支持有清晰边线的矩形合并单元格。0.1.6 支持三行三列以上、对齐清楚的无边框表格，并在 PDF 中保留无边框样式。独立插图支持自动定位或按原图像素提供裁片范围，最低版本为 0.1.4。默认准备 PDF，也可选择 Word 或两者。文字或版式需要确认时会返回具体位置。文件继续由原会话的回复队列投递。

连续留白分开的两栏或三栏横排正文可从左到右逐栏读取，复刻为单栏可编辑文档。含表格或插图的混排区域继续按现有版式流程处理。

获准读取历史、附件和媒体回复的原请求者，可以在同一会话用 `wechat_document_revision` 找回图片复刻的 Word 原稿，按成品编号和摘要修改主标题字号。原稿留存，默认从新版 Word 准备新版 PDF。

应用页的「群聊」展示所选连接的本机群快照。主人可在群详情提交免打扰设置。后台声明支持对应操作时，主人也可以确认修改群名称或设置、清空本人群昵称。各项操作分别查询原生回执。主人可授权大肥鱼在本地聊天通过 `wechat_group_mute` 为指定群设置免打扰。主人也可从投递记录核对并撤回本人已发送的文字或单个已接受片段。

配置停机的旧版隔离快照后，对应连接可在应用页预演并保存接入摘要。旧建议权限、既有回执和待核对回执分别展示，接入后仍需主人核对登录和回复范围。

对已接续的会话，`wechat_read_legacy` 可在当前历史授权范围内按需查阅经过校验的旧资料，原始陈述与有来源的旧记忆分开分页。
