# 版本记录

## 0.18.0

- 增加由宿主统一管理的 `app_action` 持久互动任务声明：可对已读取的确切视频设置点赞期望状态，或回复已读取的确切父评论。
- 点赞、回复评论、评论读取与作品发布分别授权，所有新增互动许可默认关闭。回复绑定父评论编号与宿主签发的来源版本；版本变化、撤权或来源失效均阻止新的提交。
- 创建任务、准备核对和提交分离；未知结果仅查询原任务，旧的仅自己可见作品不会被互动恢复路径重新发布。
- 本版只通过离线合成场景与本机入口验证。抖音网页 DOM 观察不是平台服务端回执，未进行真实点赞或评论回复验收。

## 0.17.0

- 增加独立授权的普通视频页面评论读取，通过现有应用观察工具续读或刷新。保留评论编号、作者及视频出处，评论不混作音轨或视频正文。
- 评论区加载失败、明确无评论和已读完分别处理；续读位置失效返回具体原因。收窄读取范围、重新登录或撤权同时阻止旧缓存和晚到结果。
- 仅使用合成页面、模型替身和正常本机入口验证，本版本未新增真实平台互动。

## 0.16.0

- 支持新版创作者页面的 `create_v2` 发布回执及精确字符串作品编号。提交结果未知时，通过同一专属账号的作品管理页面，按原任务文案、时间和可见范围只读恢复编号；重复候选、隐私不符及资料不完整均保持待核对，不重新发布。
- 取消任务不触发文案扫描；恢复后的编号由宿主账本保存。已发布任务不继续显示旧的提交失败进度。

## 0.15.0

- 普通账号创作者中心发布接入通用成品与任务账本。发布许可与读取许可独立，支持明确选择可见范围，实际文件、文案和设置核对后才提交。
- 适配 Windows 上传路径、编辑页切换及私密选项；分阶段返回安全诊断，未知提交只查询原任务。

## 0.13.0

- 普通视频后续编号增加独立许可的本机画面读取。宿主从同一确切媒体原件按批解码画面，每批默认 6 帧、最多 12 帧，并返回媒体摘要、实际 PTS、逻辑帧位置与续读位置；画面分析结果是外部资料，不是指令，也不表示完整观看。

## 0.12.0

- 普通视频后续编号增加独立许可的本机音轨读取。确切原件经 FFmpeg 与已启用的本机识别工具按窗口转写，可续读，区分无音轨、无人声和服务失败；不依赖播放采样结果，不把转写当作画面理解或完整观看。
- 增加普通网页登录管理输入 schema，旧文字、播放、搜索及 OAuth 配置不自动扩大授权。

## 0.11.0

- 为宿主从首页核验的视频后续编号增加独立授权的普通网页静音播放采样；首页仍只读文字，旧文字许可不自动获得播放权限。采样只记录实际主媒体播放区间，不代替音轨、画面理解或平台写入回执。

## 0.10.0

- 网页文字读取默认保持首页范围；主人另行扩大范围后，宿主仅可对首页实际发现的确切视频页面签发逐项核验的后续读取编号，不表示视频已观看、音轨已转写、点赞或发布。

## 0.9.0

- 增加由 Windows 宿主单独开启的已保存网页登录资料主页文字只读连接；浏览器资料、来源、授权版本与分页仍由宿主保管，读取不表示完整观看、点赞或发布。

## 0.8.0

- 增加 Windows 桌面手动续期，保留仍获准的原投稿任务与作品续读进度。

## 0.7.0

- 增加独立视频发布授权、单文件与分片上传、创作发布账本及原作品状态核对。

## 0.6.0

- 抖音扫码支持显式追加作品列表授权。按原账号分页读取作品编号，区分四页上限与列表自然结束。

## 0.5.1

- Windows 成长站在独立扫码窗口打开官方授权页，回跳经本机核验后自动返回应用卡片。关闭窗口可取消本次授权。

## 0.5.0

- 增加 Windows 隔离 Edge 官方播放器静音采样，报告实际已播放区间。

## 0.4.0

- 允许从已授权搜索结果继续核对同一作品的官方播放器入口，独立于实际播放证据。

## 0.3.0

- 在 Windows 应用页接入抖音官方网页扫码授权、账号身份核验、到期显示和移除本机连接。

## 0.2.0

- 为 Windows 增加独立授权的本人作品状态查询，结果绑定指定作品和核对时间。

## 0.1.0

- Windows 隔离本地站点支持获准关键词的抖音官方视频搜索。
- 提供结果出处、分页续读、过期诊断及本地撤权。

## 0.14.0

正式站点切换为普通网页登录接入。移除开发者授权、API 搜索及 API 发布的能力声明和入口，保留旧资料。界面将源码改为接入版本。
