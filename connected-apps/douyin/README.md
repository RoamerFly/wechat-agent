# 抖音接入版本

通过普通抖音账号登录，保存专属网页登录状态。登录过期时在应用详情重新登录。

主人可以分别允许首页和视频页面文字读取、静音播放观察、音轨转写及画面分析。实际内容定位和读取由抖音接入负责，解码、语音识别和视觉分析复用公共工具。模型按已取得的内容和来源继续任务。

评论读取使用独立许可，通过 `app_observe(field=comments)` 读取宿主已发现的视频。返回页面实际加载的评论、评论编号与作者；按原请求续读，`refresh=true` 从头更新。默认请求 20 条，可调整；达到本次读取资源边界时返回实际条数和继续位置。评论者观点与视频原话分开。本轮已通过离线页面和正常聊天入口回放，真实抖音评论页面仍待验证。

点赞和回复评论使用通用的 `app_action` 持久互动任务。点赞必须明确 `desired=true`（点赞）或 `desired=false`（取消点赞）；回复必须引用已经通过评论读取取得的 `comment_id`。宿主把父评论的精确来源版本一起绑定进任务，评论内容或来源版本变化时不会继续提交。点赞、回复评论、评论读取和作品发布分别授权，全部默认关闭。`create` 只创建可审计任务；通过准备、授权与来源核对后才登记提交。未知结果只能查询原 `job_id`，不创建新任务重复点击或重复回复；旧的仅自己可见作品也不会因为互动任务而再次发布。

互动功能目前只经离线合成场景和本机入口验证。页面 DOM 观察不等于抖音服务端回执，尚未进行真实抖音点赞或评论回复验收。

普通账号已支持通过创作者中心发布单个 MP4/WebM 成品。主人单独开启发布许可后，任务核对文案与可见范围、登记提交，再查询原作品回执。回执丢失时只读核对已提交的原任务，不自动重新投稿。实际账号已完成一次仅自己可见的 18 秒作品验收；公开发布、互动真实页面和直播伴侣仍待相应验证。

历史 API 配置资料保留在宿主私有目录，正式站点取消开发者授权入口和对应工具连接。

Connected Apps/douyin 是本软件的接入版本工作目录，用于维护应用接入行为。账号登录资料、密钥和权威回执由宿主管理。目录内容不包含抖音客户端本体或其源代码。

实现范围、授权和验证边界以项目的《大肥鱼长期成长阶梯计划》和《应用接入与项目工具规范》为准。
