# 安装与撤权

本应用独立于微信和哔哩哔哩。启用需要在站点私有目录单独准备搜索设置及平台批准的应用凭据。应用设置可用后自动显示获准关键词，无需重启。

设置 `enabled=false` 或移走私有配置文件可停止后续搜索和续读。应用令牌到期后，在开放平台生成新令牌并更新私有配置。来源副本可以安装到大肥鱼家目录，运行权限继续由宿主管理。

0.2.0 保留原搜索设置和会话续读。本人作品需要单独登记，现有搜索应用令牌不会被用于账号作品。删除本人作品私有配置或停用其中的授权即可关闭相应入口。

0.3.0 新增独立账号授权。原有搜索和本人作品配置继续读取，无需重写。新授权保存在宿主的 apps/douyin/authorization.json，不放入家目录的应用源码副本。移除连接清除其中的账号令牌，其他两份授权独立管理。

0.4.0 新增可选的 follow_public_videos，旧搜索配置缺少该字段时继续按原方式搜索。开启后重新搜索即可取得跟进编号，无需重建观察库。

0.5.0 新增可选的 sample_public_playback，默认关闭。开启前需要同时允许跟进搜索结果。旧配置无需修改。

0.6.0 读取既有的账号授权记录时，作品列表权限默认为关闭。主人可按需重新扫码选择此权限。解除连接或重新授权会让旧授权对应的列表游标失效。

0.7.0 读取旧账号授权记录时，发布权限默认为关闭。主人可选择重新扫码，现有搜索、作品读取及其私有设置按原授权继续使用。发布任务按同一账号和授权版本保存上传进度，重新扫码变更授权后不能使用旧授权继续写入平台。

0.8.0 兼容现有账号连接和账本。旧连接在原访问期内仍可使用，首次重新扫码后可按平台返回的期限手动续期。对同一账号保有原授权的续期保留已有发布任务和读取游标的授权编号。解除连接会一并清除访问和续期凭据。运行旧版程序需要恢复旧版账号文件或重新扫码，旧版会拒绝未知的凭据字段。

0.12.0 将本机音轨读取作为普通网页登录的独立宿主许可，旧记录缺少 `audio_enabled` 时默认关闭。主人在已保存资料及首页、视频页文字范围内，通过 `set_read` 明确设置 `allow_audio=true`；它不要求开启 `allow_playback`。停止文字读取、降级为仅首页、重新登录或移除资料会撤销该许可。已存在的静音播放和官方 OAuth 授权保持各自原范围。

0.13.0 将本机画面读取作为普通网页登录的独立宿主许可，旧记录缺少 `visual_enabled` 时默认关闭。主人在已保存资料及首页、视频页文字范围内，通过 `set_read` 明确设置 `allow_visual=true`。它与播放、音轨分别授权，不代表可读取其他页面、评论、点赞、发布或完整观看。媒体摘要、总帧数和步长变化时，旧画面进度不复用；使用 `refresh=true` 从头读取当前媒体。

`config.schema.json` 继续只描述官方搜索配置，不添加网页音轨字段。新增 `web-read.schema.json` 说明宿主的网页登录管理输入；许可仍保存在宿主私有记录，不能把家目录中的 schema 或可编辑源码当作授权。音轨进度按当前身份、许可、来源及媒体摘要保存，重启可从最后成功窗口继续。旧进度和媒体不同不能静默合并，也不会重建全部记忆。停用或回退旧程序前先停止新读取；保留原件及进度，由理解对应字段的版本恢复，不把不兼容记录改写成旧格式。

0.14.0 取消正式站点开放平台连接。旧配置及回执继续保存，未决任务须按原编号核对，不能转为新普通账号发布。普通网页登录资料及其独立许可沿用原存储。

0.18.0 为普通网页登录记录增加评论读取、点赞和回复评论的独立许可。旧记录缺少这些字段时全部视为关闭；升级不会创建互动任务、不会补发旧评论，也不会重新发布旧的仅自己可见作品。主人先通过 `set_read` 明确保存 `allow_comments`，再通过 `set_interactions` 按需保存 `allow_likes` 与/或 `allow_replies`。互动任务保存于宿主的应用任务账本；迁移期间或升级后结果未知的旧任务只能按原任务编号查询，不能重建为新的点击或回复。
